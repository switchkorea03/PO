# 간단한 PO 관리 · 업무 달력 목업

기존 업무 워크벤치 대신 PO 목록, 파일 등록, 자동 업무 달력에 집중한 새 목업입니다. 이전 ui-mockup 폴더는 보존합니다.

## 실행

```powershell
cd po-calendar
npm run dev
```

http://localhost:4173/ 에서 확인합니다. 날짜 계산 테스트는 `npm test`로 실행합니다.

## 사용 흐름

1. PO 파일 등록에서 Excel(.xlsx/.xls) 또는 PDF를 선택합니다. 드래그 또는 여러 파일 선택이 가능합니다.
2. 목업의 샘플 인식 결과를 실제 내용으로 수정합니다. 국내/해외, 고객사, 번호, 모델, 수량 및 기준 날짜를 확인합니다.
3. 등록 후 국내 3건, 해외 4건의 일정이 생성됩니다.
4. 달력에서 날짜를 선택하고 오른쪽 업무를 완료 처리합니다. PO 정보에서 날짜를 수정하면 해당 일정이 이동합니다.
5. 자동 일정 규칙에서 예시 업무명을 변경할 수 있습니다.

## 날짜 규칙

| 구분 | 기준 | 표시 |
|---|---|---|
| 국내 | 출고예정일 -2일 | 출고 2일 전 업무 |
| 국내 | 출고예정일 -1일 | 출고 1일 전 업무 |
| 국내 | 납기일 | 납기일 |
| 해외 | PO 수령일 | PO 수령 일정 및 당일 업무 |
| 해외 | 수령일이 속한 주의 다음 주 화요일 | 다음주 화요일 업무 |
| 해외 | ETA +1일 | ETA 다음날 업무 |

주는 월요일~일요일로 계산합니다. 예를 들어 2026-10-13 수령 → 2026-10-20 화요일입니다. 공휴일·주말도 날짜 그대로 표시합니다. ETA 미정은 날짜 미정 목록에 남고, 입력하면 자동 배치됩니다.

## 목업 범위

실제 파일 선택 및 파일명/형식 확인, 등록·수정, 일정 계산, 검색·필터, 완료 표시가 동작합니다. 파일 내용 분석과 PDF OCR은 연결하지 않았으며 인식값은 명시적인 예시입니다. 원본 파일을 외부로 전송하거나 저장하지 않습니다. 데이터는 브라우저 메모리에 존재하며 새로고침하면 샘플로 복원됩니다.
