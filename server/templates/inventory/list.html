데스크탑에서 ERP 연결하기
  1. GitHub의 소스를 데스크탑으로 내려받고 웹앱 실행 환경을 준비합니다.
  2. 기존 PO 데이터와 원본 파일은 별도 백업으로 복원하고, 서버 설정과 인증키를 데스크탑에 설정합니다.
  3. iCUBE 담당자와 재고 조회 경로(API·조회용 DB·파일 전달)를 확인합니다.
  4. 자사품목명과 ERP 품목코드·창고·단위를 연결한 뒤 재고 수량과 갱신 시각을 검증합니다.

지금 단계에서는 ERP 로그인 정보나 API 키를 입력하지 않습니다.
