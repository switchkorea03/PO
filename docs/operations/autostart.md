# Windows 로그인 시 로컬 서버 자동 실행

현재 사용자 시작프로그램에 `PODesk-LocalServers.lnk`를 등록했습니다. Windows 로그인 후 `ops/start-on-login.ps1`이 숨김 실행되어 DB·실제 웹앱·파일 인식 worker·UI 목업을 준비합니다. 브라우저 창은 열지 않습니다. 문자 worker는 기존 공급자 설정이 있을 때만 실행하며, 실제 문자 인증정보를 새로 설정하지 않습니다.

- 실제 업무: <http://127.0.0.1:8000/>
- 화면 검토 목업: <http://127.0.0.1:4174/>
- 실행 기록: `.runtime/autostart.log`
- 기존 프로세스/포트를 확인해 반복 실행 시 중복 서버·worker 생성을 피합니다.
- 다른 프로그램이 포트를 점유하면 종료하거나 덮어쓰지 않고 오류를 남깁니다.

## 다시 설치·해제

작업 폴더에서 실행합니다.

```powershell
.\ops\install-autostart.ps1
# 자동 시작 해제 (저장 데이터와 현재 실행 중인 서버는 유지)
.\ops\install-autostart.ps1 -Remove
```

작업 폴더를 이동하면 자동 실행도 새 위치에서 다시 등록해야 합니다. 현재 등록은 PC가 꺼진 동안의 운영이나 로그인 전 실행을 제공하지 않습니다.

## 검증

실제 로그인 시 사용하는 Windows PowerShell로 시작 스크립트를 두 번 실행했습니다. 기존 웹·파일 인식·목업 프로세스 ID가 유지되고 중복 프로세스가 생기지 않았습니다. 등록된 `.lnk`를 직접 실행하여 성공 로그와 두 주소의 HTTP200 응답도 확인했습니다. PC 재부팅 자체는 수행하지 않았습니다.

## 목업과 실제 앱을 수정하는 방식

실제 웹앱에서 기능과 화면을 모두 수정할 수 있습니다. 목업은 메뉴 배치·화면 구성을 실제 데이터에 영향 없이 먼저 비교하는 선택 도구입니다. 목업에서 확정한 화면은 실제 웹앱 코드에도 반영해야 하며 두 사이트가 자동으로 동기화되지는 않습니다. 일상적인 업무와 향후 수정 확인은 실제 웹앱을 기준으로 합니다.
