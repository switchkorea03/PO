## 확인된 결과

서버 테스트84개 모두 통과(건너뛴 테스트 없음), migration 변경 누락 없음. 실제 PostgreSQL17에서 수량 동시성·업무 이력·문자 outbox를 검증했습니다. 문자 테스트는 fake 및 HTTP 계약 테스트이며 실제 휴대폰 발송은 하지 않았습니다.

실제 프론트엔드 적용: 목업 기반 공통 메뉴·스타일·달력·현황·PO 입력/상세·업로드 확인·문자 설정/이력을 실제 저장 데이터에 연결했습니다. 전체 브라우저20개 시나리오가 통과했고, 브라우저 내장 PDF 뷰어 대신 보호된 PNG 미리보기로 보완한 뒤 해당 화면4개 너비를 재검증하여 모두 통과했습니다. PDF 렌더링 크기·페이지 범위·인증·동일 출처 제한과 실제 업무 현황 필터를 서버 테스트로 확인했습니다. 화면별 소스와 변경 안내는 `docs/operations/frontend.md`를 참조하세요.

고객 중복 수정: 같은 고객명을 반복·동시 등록해도 기존 고객을 재사용하며 DB 고유 제약으로 중복을 막습니다. 기존 중복 고객은 연결 PO를 보존해 정리합니다. 5회 추가·새로고침 후 한 항목 유지 브라우저 테스트와 실행 중 앱의 범진전자 5회 재선택도 확인했습니다.

범진전자 실제 업로드 PDF 확인: 텍스트 판독은 성공했으나 기존 범용 파서가 두 단의 표 머리글, 규격·납기의 줄바꿈, 콜론 없는 PO 번호를 지원하지 않아 품목이 비어 있었습니다. 해당 양식용 파서를 추가하고 실제 파일의 품목·수량·단가·통화·납기를 원본 및 확인 화면과 대조했습니다. 기존 미확정 draft만 재처리했으며 PO 등록은 확정하지 않았습니다. 추가 합성 회귀 테스트5개는 여러 품목의 납기 분리, 규격 보존, 누락 납기 추정 금지, 본문 외 행 제외, PDF 판독 연동을 검증합니다. 다른 고객 양식의 정확도는 별도 인수 대상입니다.

솔루엠 베트남 실제 업로드 PDF 확인: 표 머리글과 품목 데이터가 여러 줄로 분리되고 수량 소수부의 마지막 자리가 다음 줄로 추출되어 기존 행 기반 파서가 인식하지 못했습니다. PDF 머리글 좌표로 열·품목 행을 구분하고 같은 수량 셀의 줄바꿈만 연결하도록 보완했습니다. 실제 원본의 수량×단가와 공급가액이 일치함을 확인했습니다. 공급자와 베트남 구매자를 구분하고 해외 기본값을 제안하되 수령일·ETD는 원문 납기에서 추정하지 않습니다. 신규 고객 추가 시 인식된 고객명·해외·USD를 유지합니다. 합성 서버 테스트6개와 PC·모바일 등록 흐름2개를 추가 검증했습니다. 기존 미확정 draft만 재처리하고 원문 인식 결과의 이전 버전은 로컬 복구 기록에 보관했습니다.

## 최종 검토 반영

독립 코드 검토에서 발견한 중요 문제7개를 재현 테스트로 확인하고 수정했습니다.

- 미완료 회차만 사유와 함께 취소하여 배정을 해제하고, 다른 회차·완료 기록을 유지합니다. 주문 자체의 취소수량은 배정 해제 후 잔량 취소로 기록합니다.
- 추가 문자 이벤트는 순번 커서 대신 개별 처리 여부로 소비합니다. 두 DB 연결에서 낮은 순번의 거래가 나중에 커밋되어도 누락되지 않습니다.
- 완료 업무의 체크 해제는 명시적인 재작업으로 처리합니다. ETD가 삭제된 업무는 재작업 시 보류되고 알림에서 제외됩니다.
- 수정 PO 확인 화면에서 기존 품목을 직접 선택할 수 있습니다. 중복·변경·미기재 코드의 자동 연결을 강제하지 않습니다.
- PO 필드·가격·통화·품목·수량·납기 등의 변경 전후 값을 이력에 저장하고 화면에서 조회합니다.
- 재작업 시 이전 완료 기록의 ERP 안내는 이력에 남기고 현재 통화·거래유형의 안내로 갱신합니다.
- 출고 완료 후에도 ETA를 별도로 수정하며 수량·출고 실적은 유지합니다.

경미한 지적이었던 업무 상세의 대상 품목·수량 표시도 반영했습니다. 실제 고객 파일, 실제 문자 수신, 회사 운영 배포는 아래 인수 조건으로 남아 있습니다.

## 회사 환경에서 남은 인수

- 실제 고객의 국내 PDF·해외 PDF·스캔 PDF·xlsx·xls 각1건 이상의 고객별 인식 품질. 현재 테스트는 비식별 합성 fixture입니다.
- 회사가 사용할 문자 공급자 계정·API 인증정보·사전 등록 발신번호·본인 수신번호 설정과 실제 수신1건 대조.
- 회사 내부 URL·HTTPS·운영 사용자·배포 서버·상주 서비스·백업 경로·주기 확정.

이 항목들은 로컬 구현과 분리한 운영 인수 조건입니다. 서비스 가입·요금 결제·회사 운영 배포·ERP/메일/공유 Excel 연결은 진행하지 않았습니다.
