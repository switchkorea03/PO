# 스펙 자사품목명 자동 입력 및 납기일 일괄 적용

- 첨부 이미지의 11개 품명(JT1140WJ-BEM, JES1612GWAS, JS1267EM, JTP1135JEM, JT1126EM, JT1127WEM, JS6901EM, JT1136SHAEM, JT-S1102PEM, JT1152EM, JT1138FEM)을 스펙에서 인식합니다. 기존 고객품목명 매핑도 유지합니다.
- 대소문자, 줄바꿈과 하이픈 표기 차이는 정규화하며 다른 모델의 접두부·접미부로만 나타나는 부분 일치는 자동 연결하지 않습니다. 복수 모델이 함께 나오면 하나를 추측하지 않습니다. 직접 입력한 자사품목명은 유지합니다.
- PDF 인식 확인·직접 등록·수정·재등록 화면은 자사품목명 → 고객품목명 → 스펙 순서입니다. PO 목록·상세·엑셀에서도 같은 명칭과 순서를 사용합니다.
- 전체 품목 납기일을 선택하고 전체 품목에 적용을 누르면 입력 중인 모든 행에 적용됩니다. 이후 개별 수정할 수 있고 새로 추가한 품목도 마지막 일괄 적용일을 사용합니다. 실제 저장은 PO 저장 버튼에서 처리합니다.
- 기존 국내 PO의 납기일을 일괄 수정해 저장하면 해당 미출고 배정과 업무 일정도 갱신합니다. 완료된 출고실적은 이동하지 않으며, 해외 요청납기는 ETD 기반 일정을 변경하지 않습니다.
- 전체 서버 테스트 126개 통과. 브라우저에서 이미지 11개 모델의 자동 입력, 수동값 유지, PDF 업로드 후 5개 품목 일괄 납기 적용·저장·재조회, 기존 PO 변경 후 달력 갱신 및 목록·엑셀 동작을 확인했습니다.
