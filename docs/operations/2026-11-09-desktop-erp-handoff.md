# 데스크탑 이전 및 iCUBE 재고 연결 인계

## 현재 완료 범위

로그인 후 `재고 확인` 메뉴(`/inventory/`)에서 자사품목명·ERP 품목코드·창고·현재 재고·가용 재고·웹앱 PO 미출고 수량·단위·최종 갱신 상태를 조회합니다. 자사품목명, 고객품목명, 스펙, 고객사, PO번호 검색을 지원합니다. 표준 품목과 현재 PO의 자사품목명을 함께 표시합니다. 자사품목명이 미입력·미매핑인 품목은 먼저 PO에서 연결해야 합니다.

ERP는 아직 연결하지 않았습니다. 조회되지 않은 재고는 `None`으로 유지하고 화면에 `—`와 `ERP 미연결`을 표시합니다. 0개 재고로 간주하지 않습니다. 새로고침 버튼은 비활성입니다. 기준 재고 시각도 조회 전으로 표시합니다. PO 미출고 수량은 현재 웹앱의 수량-취소수량-완료출고량이며, ERP 재고를 예약하거나 출고 가능 수량을 보장하는 값이 아닙니다. 취소·휴지통 PO 및 취소 출고는 집계에서 제외하고 서로 다른 단위는 합산하지 않습니다.

## GitHub로 옮길 것과 별도로 옮길 것

- **GitHub:** 검토한 소스, 마이그레이션, 의존성 파일, 실행 스크립트, 문서. 이번 작업에서는 원격 저장소로 업로드하지 않았습니다.
- **별도 비공개 백업:** PostgreSQL 데이터, PO 원본 파일, `server/.env`의 설정·인증 정보. 이 정보는 GitHub의 소스 다운로드만으로 복원되지 않습니다.
- `.venv`, `.runtime`의 실행 파일·DB, `node_modules`는 새 PC에서 준비합니다. `.runtime` 전체를 무작정 덮어쓰거나 삭제하지 않습니다.

현재 `.gitignore`는 `.env`, private_media, .runtime 등을 제외합니다. 다른 이름으로 복사한 인증 파일이나 백업이 섞이지 않았는지 업로드 전 파일 목록을 확인합니다.

기존 데이터 보존 절차와 실행 환경은 `docs/operations/backup-restore.md`, `deployment.md`, `autostart.md`를 따릅니다. 노트북에서 `ops/backup.ps1 -Destination <새 백업 경로>`로 DB와 원본을 함께 백업합니다. 복원은 기존 절차에 따라 새 DB·새 media 위치에서 먼저 검증하고 웹앱 설정을 연결합니다. 코드 복사만으로 기존 로그인 계정과 PO 기록이 생기지 않습니다.

## 데스크탑 연결 단계

1. 같은 소스를 내려받고 Python/PostgreSQL/OCR 의존성을 설치합니다. 비공개 서버 설정을 준비하고 migrate/check를 실행합니다.
2. 기존 데이터와 원본 백업을 복원하고 PO 목록·파일 미리보기·재고 화면을 확인합니다.
3. 데스크탑의 iCUBE 버전, 접속 서버, 회사·사업장, 재고 조회 화면, 품목코드·창고·단위 정보를 확인합니다.
4. 담당자와 허용된 조회 경로를 결정합니다: 공식 API, 승인된 조회용 DB 인터페이스, 또는 재고 파일 전달. 로그인 가능 여부만으로 DB 접근 권한을 가정하지 않습니다.
5. `server/inventory/providers.py`의 `get_inventory_provider()`에서 실제 조회 공급자를 선택하도록 확장합니다. `fetch([(자사품목명, 단위), ...])`는 같은 키로 `StockSnapshot`을 반환합니다. ERP 코드 매핑·회사·창고 범위·단위 변환을 실제 계약에 맞춰 추가합니다. 현재 사양만으로 임의의 API 주소나 DB 테이블을 만들지 않습니다.
6. 재고의 기준(현재고/가용/예약/불량/위탁 등)을 합의하고 iCUBE 화면 수량과 대조합니다. `observed_at`은 페이지를 연 시간이 아닌 실제 재고 관측 시각으로 기록합니다.
7. 갱신 주기·실패 표시·오래된 재고 판정·호출 제한을 구현하고, 연결 끊김과 재연결도 검증한 뒤 사용합니다. ERP 연결 전에는 공급자의 `connected` 상태를 켜지 않습니다.

아직 미구현: 실제 ERP 조회, 인증, 품목코드 매핑 저장, 창고 필터, 동기화 이력, 주기적 갱신. 이 항목은 데스크탑의 실제 연동 경로 확인 후 마무리합니다. 재고 화면은 현재 연결 준비용이며 실시간 연동 완료 상태가 아닙니다.
