# PO 웹앱 개선 적용 — 2026-10-27

실제 업무 웹앱: http://127.0.0.1:8000/orders/

## 적용한 변경

1. 조회 화면의 수량·단가·공급가액에 천 단위 구분을 적용했습니다. Decimal을 부동소수점으로 변환하지 않아 소수 자릿수 정밀도를 보존합니다. 숫자 입력칸은 입력 가능한 숫자를 유지하고 품목 미리보기에 구분 기호를 표시합니다.
2. PNG 파일 업로드, 내용 검증, 로컬 OCR, 로그인한 사용자용 원본 이미지 미리보기를 추가했습니다. 기존 PDF·Excel 기능은 유지합니다. PNG는 20MiB 및 2,500만 화소 이하를 지원합니다. OCR 결과는 원본과 비교 후 확인합니다.
3. PO 목록과 상세에 삭제 기능, 목록의 휴지통에 복원 기능을 추가했습니다. 삭제된 PO는 목록·달력·현황·문자 후보에서 제외됩니다. 원본·품목·출고실적·업무·감사 이력은 삭제하지 않습니다. 행 버전 검사로 오래된 화면의 삭제 요청을 차단합니다.
4. 고객품목명과 자사품목명을 별도로 저장하고 `고객품목명 (자사품목명)`으로 표시합니다. 제공된 4개 연결을 자동으로 채우며 수동 수정과 수정본 등록 시 기존 연결 보존을 지원합니다.
5. 기본 국내 업체는 범진전자·SJI·SJIT, 해외 업체는 켐트로비나·솔루엠·리모트솔루션으로 등록했습니다. 고객 선택에서 국내·해외 그룹을 표시합니다. 기존 고객과 PO는 보존했습니다.
6. PO 목록을 품목별 한 줄 표로 변경했습니다. 발주서 등록일(시스템 등록일), 고객사, 구분, PO 번호, 품목명, 수량, 단가, 공급가액, 통화, 납기일, 출고·잔량, 관리 기능을 표시합니다. 작은 화면에서는 표 내부 가로 스크롤을 사용합니다.

## 휴지통 PO 파일 재업로드

- 휴지통 PO의 동일 파일을 재업로드하면 기존 정보가 채워진 재등록 입력 화면을 엽니다. PO 저장을 눌렀을 때만 수정값 저장과 복원을 함께 처리합니다. 저장 전 이탈하거나 검증이 실패하면 휴지통에 유지됩니다. 원본·품목·출고실적·업무·감사 이력은 유지하며 새 PO나 파일 사본을 만들지 않습니다.
- 현재 등록된 PO에 연결된 파일은 기존 중복 안내를 유지합니다. 복원은 행 잠금과 버전 검사 안에서 처리합니다.
- 관련 서버 테스트 39개 통과. 브라우저 테스트는 신규 파일 등록 → 목록 삭제 → 동일 파일 재업로드 → 정보 입력 화면 → 저장 전 휴지통 유지 → 수정·저장 후 복원 → 정상 PO 중복 차단을 검증합니다.

## 업로드 인식 결과 편집 표

- 입력 항목의 표시명을 품목코드 → 고객품목명, 고객품목명 → 스펙으로 변경했습니다. 기존 저장 필드와 원본 이력은 유지합니다.
- 업로드 확인 화면은 원본 확인 영역 아래에 품목별 가로 편집 표를 표시합니다. 발주서 등록일(시스템 등록일), PO번호, 고객품목명, 스펙, 자사품목명, 수량, 단가, 공급가액, 납기일, 단위, 통화를 확인할 수 있습니다.
- PO번호는 기본 정보에서 수정하면 모든 행에 반영됩니다. 품목 값은 행 안에서 직접 수정하며, 자사품목명 자동 입력·품목 추가/삭제·수정본의 기존 품목 연결을 유지합니다. 작은 화면에서는 표 내부 가로 스크롤을 사용합니다.
- 엑셀 헤더 고객품목명·스펙·규격도 인식하도록 추가했습니다. 관련 서버 테스트 41개 통과.

### 재등록 화면 누락 수정

- 새 파일의 인식 결과 화면에만 편집 표가 적용되어, 동일 파일 재업로드 시 열리는 기존 PO 재등록 화면은 카드형 품목 입력을 사용하던 누락을 수정했습니다. 직접 등록·수정·재등록·인식 결과 확인이 같은 편집 표를 사용합니다.
- 일곱 핵심 열(등록일, PO번호, 품목명, 수량, 단가, 공급가액, 납기일)을 기본 표시하고, 스펙·자사품목명·단위·통화는 품목의 추가 정보에서 수정합니다. 자사품목명은 품목명 아래에도 표시합니다.
- PO번호는 행에서 직접 수정해도 모든 행과 공통 정보에 반영됩니다. 기존 PO의 등록일은 기존 시스템 등록일을 표시합니다. 숫자는 정밀도를 유지하면서 불필요한 소수점 뒤 0을 정리합니다.
- 실제 사용 중인 PO 재등록 페이지의 변경 전 카드 컨테이너를 확인했고, PC 회귀 테스트에 재등록 편집 표 및 일곱 입력칸의 화면 내 가로 배치 검사를 추가했습니다.

### 기본 정보 가로 배치 및 품목 열 조정

- 기본 정보는 고객·PO번호·국내/해외·PO 주문일·고객 담당자·비고를 PC에서 한 줄로 배치합니다. ERP 거래유형과 PO 수령일 입력칸은 숨기되 저장된 값은 유지합니다. 신규 PO 수령일은 인식값이 있으면 사용하고 없으면 등록 당일을 사용해 해외 업무 일정 생성을 유지합니다.
- 품목 열은 품목명 → 자사품목명 → 스펙 → 수량 → 단위 → 단가 → 통화 → 공급가액 → 납기일 → 관리 순서입니다. 발주서 등록일과 품목별 PO번호 열은 제거했습니다. PO번호는 기본 정보에서만 입력하며, 스펙은 독립된 열에서 바로 수정합니다.
- 수량은 천 단위 쉼표를 포함해 표시하며 수정 후에도 구분 기호를 적용합니다. 서버로 보내기 직전에 쉼표만 제거하며 Number 변환을 하지 않아 소수 정밀도를 보존합니다. 브라우저 테스트는 소수 10자리 수량의 표시·전송·저장 후 재조회를 확인합니다.

## PO 목록 엑셀 다운로드

- PO 목록 상단의 엑셀 다운로드 버튼에서 현재 적용된 검색어·국내/해외·고객·진행상태 조건을 그대로 적용한 `.xlsx`를 내려받습니다. 기본 목록에서는 휴지통 PO를 제외하며, 휴지통을 보고 있으면 해당 휴지통 목록을 내보냅니다.
- 품목별 한 행으로 등록일·고객·구분·PO번호·품목명·자사품목명·스펙·수량·단위·단가·공급가액·통화·납기일·출고수량·잔량·상태를 포함합니다. 헤더 고정, 자동 필터, 숫자·날짜 표시 형식을 제공합니다.
- 사용자가 입력한 문자열은 수식으로 실행되지 않도록 문자 셀로 저장합니다. Excel의 유효숫자 15자리를 초과하는 값은 문자로 보존해 반올림을 방지합니다. 일반 수량·금액은 계산 가능한 숫자 셀입니다.
- 서버 테스트 15개, PC·모바일 실제 다운로드 테스트 2개 통과. 테스트 파일은 `.runtime/po-list-export-desktop.xlsx` 및 모바일 파일에 저장하며, 실제 PO 데이터는 변경하지 않습니다.

## 취소 PO 재업로드 저장 제한 수정

- 취소된 PO와 취소 후 휴지통에 넣은 PO 모두 재업로드 시 정보 입력 화면을 열고, 저장 시 취소 해제·휴지통 복원·정보 수정을 한 트랜잭션으로 처리합니다. 저장 전에는 기존 상태를 유지하며 검증 실패 시 복원도 롤백합니다.
- 같은 원본 파일뿐 아니라 새 원본에서 동일 고객·PO번호가 인식되는 경우에도 기존 PO를 재등록 대상으로 연결합니다. 정상 등록 중인 PO의 중복 안내와 행 버전 검사는 유지합니다.
- 기존 완료 출고·취소 회차·품목별 별도 취소수량·완료 업무 및 처리 이력은 보존합니다. PO 취소로 중단된 미배정 잔량은 새 출고 회차와 업무로 생성하고, 해외 PO 단위 업무는 완료 단계 기록을 유지하며 다시 활성화합니다.
- 서버 전체 테스트 112개와 PC·모바일 취소/휴지통 재업로드→입력 확인→저장→재등록 테스트 2개 통과.

## 목록 납기일 직접 수정 및 달력 업체 기준 집계

- PO 목록 각 품목의 납기일 입력칸과 저장 버튼을 제공합니다. 저장 후 현재 검색·필터를 유지하고, 오래된 화면의 동시 수정은 행 버전으로 차단합니다. 취소·휴지통 PO는 먼저 재등록합니다.
- 국내 납기 변경은 해당 품목의 미완료 출고 배정과 업무 날짜를 함께 갱신합니다. 다른 품목과 묶인 회차는 수정한 품목만 별도 회차로 분리합니다. 완료된 출고실적 및 다른 품목의 납기는 유지합니다. 해외 요청납기는 ETD 기반 업무를 변경하지 않습니다.
- 달력의 같은 날짜·같은 업무 건수는 고유 업체 수로 집계합니다. 한 업체에 여러 품목·회차·PO가 있어도 1건이며, 개별 업무·완료 체크 이력은 유지합니다. 납기 표시도 업체·날짜 기준으로 묶고, 여러 PO가 묶인 납기를 누르면 해당 업체의 PO 목록을 엽니다.
- 오늘/지연 업무 카드와 선택 날짜의 업무 건수도 업체 기준으로 표시합니다. 진행 중 PO·ETD 미정 회차 카드는 각기 PO·회차 기준을 유지합니다.
- PC·모바일에서 목록 납기 수정 → 다른 품목 납기 유지 → 달력 이동 → 업체 1건 집계 → 검색 조건 유지까지 검증했습니다.
