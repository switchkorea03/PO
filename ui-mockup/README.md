# FlowPO 동적 UI 목업

PO 주문·출고 자동화의 개발자 상세 설계용 정적 SPA입니다. 모든 데이터와 동작은 브라우저 메모리에만 존재하며 실제 Outlook, iCUBE, 파일시스템 또는 공유 Excel에는 연결되지 않습니다.

## 실행

```powershell
cd ui-mockup
npm run dev
```

브라우저에서 `http://localhost:4173/#/`를 엽니다. 우측 상단의 **초기화** 버튼으로 모든 샘플 상태를 복원할 수 있습니다.

테스트는 다음 명령으로 실행합니다.

```powershell
npm test
```

## 주요 경로

| 경로 | 화면 | 확인 포인트 |
|---|---|---|
| `#/` | B1 오늘의 업무 | 우선 처리 업무, 오늘·내일 일정 |
| `#/orders` | PO 업무 목록 | 검색, 담당자·국내/해외·상태 복합 필터 |
| `#/review/SE-2408` | P1 PO 검토 | 원본 영역과 추출 필드 연동 |
| `#/orders/BJ-10241` | 국내 D1 상세 | 생산요청 직접 입력, 분할납품 실제수량 확정 |
| `#/orders/CV-8821` | 해외 D1 상세 | QY 발송 → 공장 회신 → QP 입력 → QY 연결 → 후속업무 |
| `#/operations/documents` | 문서 | 문서 버전 및 발송본 상태 |
| `#/operations/mail` | 발신 메일 | Outlook 초안, 수신자·첨부 검토 |
| `#/operations/exceptions` | 예외·정정 | 담당자 조치, 완료 원본 불변 원칙 |
| `#/operations/excel` | Excel 복사 | 제한된 최종 실적 열, 행·전체 복사 |
| `#/master` | 기준정보 | 고객사, 품목·단위, 템플릿, 수신자 그룹 |

## 샘플 상호작용

- PO 목록에서 고객사나 모델을 검색하고 필터를 조합합니다.
- P1 화면에서 추출 필드를 누르면 왼쪽 PO 원본의 대응 영역이 강조됩니다.
- 국내 주문에서 생산요청 수량을 직접 입력하거나 2차 실제 납품수량을 확정합니다. PO 수량을 초과하면 차단됩니다.
- 해외 주문에서 현재 QY 연결을 확정하면 고객메일, 수입선적등록, 입고처리, 내부메일 순으로 다음 동작이 열립니다.
- 문서·메일 버튼은 검토용 대화상자를 표시합니다. Excel 복사는 실제 클립보드에 탭 구분 데이터를 쓰며, 브라우저가 차단하면 직접 복사 가능한 텍스트를 표시합니다.
- 해외 상세의 단계 체험 선택에서 QY 초안, 공장 회신 대기, QP 입력, 수량 차이 상태를 탐색할 수 있습니다.
- 완료된 주문에서 정정 후 수량과 사유를 입력하면 예외·정정 화면에 별도 이력이 생성됩니다. 원본 수량은 보존됩니다.
- PO 검토 화면에서 동일 파일 중복 차단, 부분납품 후 수정본 비교·승인·반려를 체험할 수 있습니다.
- QY / QP 다대다 직접선택 창에서 복수 문서를 선택할 수 있습니다. 추가 후보는 연결 방식 확인용 샘플입니다.
- 국내 분할 회차 추가·예정일 변경·실제일 입력과 ERP/납품서/구매팀 메일 확인을 지원합니다. 수량 확정 후 후속 확인까지 완료해야 주문이 완료됩니다.
- 해외 부분선적은 후속 처리가 끝나도 잔량을 표시합니다. Excel에는 확인된 납품·입고 실적만 표시합니다.

## 구현 경계

- 구현됨: 정보구조, 화면 상태, 단계 잠금, 상태 전환, 검증 메시지, 반응형 레이아웃, 샘플 감사 이력.
- 목업 전용: 샘플 문서 미리보기, 메일 초안 검토, ERP 등록 완료 기록, 기준정보 편집 예시. 기준정보 편집은 실제 마스터 데이터를 변경하지 않습니다.
- 제외됨: 수신메일 자동검색·판독, BL 업로드·저장·OCR, 공유 Excel 읽기·쓰기·완료추적, 실제 인증·DB·ERP·Outlook 연동.
