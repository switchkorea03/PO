# UI 목업 검증 기록

검증 대상: 실제 업무 앱(8000)과 별도인 목업(4174). 샘플 데이터를 초기화하고 검증합니다.

- 1440 / 1280 / 768 / 360px의 4개 너비에서 화면별 가로 넘침 확인.
- 달력, PO 목록, PO 상세, 업로드 확인, 문자 설정, 발송 이력, 계정·권한, 사용 안내 화면 탐색.
- ERP 2개 처리의 두 번째 체크 완료로 전체 완료 상태 전환.
- 인보이스+ERP 업무를 다른 평일로 이동한 뒤 새로고침하여 수동 날짜 보존 확인.
- 미정 ETD에 토요일 10.17 입력 → 후속 ERP 업무일 10.19 월요일 확인.
- 주문 100 / 1차 출고 70 / 잔량 30 확인 및 추가 회차 과다 배정 차단.
- 확인 화면에서 예시 PO 등록 후 상세 화면 진입, 같은 고객의 필터 중복 방지.
- 페이지 JavaScript 오류 없음 확인.
- 날짜·잔량 규칙 5개 자동 테스트 통과.

브라우저 검증 총 60개 체크. `preview-desktop.png`, `preview-mobile.png`, `preview-po.png`는 검증 과정에서 생성한 화면입니다. PC·모바일 캡처를 직접 열어 레이아웃도 확인했습니다.

초기 브라우저 검증에서 PO 상세의 선택 탭을 유지하는 동작을 테스트가 고려하지 못해 탭을 명시적으로 선택하도록 수정했습니다. 모바일에서는 표가 그리드의 최소 너비를 밀어내는 문제를 발견해 카드/스택에 `min-width:0`을 적용했습니다.

실제 파일 인식·정밀 수량 계산·운영 DB·문자 수신·인증·권한의 보안 검증은 이 목업의 검증 범위가 아닙니다. 실제 서비스의 테스트를 대체하지 않습니다.
