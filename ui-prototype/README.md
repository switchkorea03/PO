# PO Desk — 최종 설계 기반 UI 목업

기준: `docs/superpowers/specs/2026-10-16-po-management-calendar-design.md` 및 고객 중복 방지·범진전자 PDF 확인 흐름에 관한 후속 협의.

실행 중인 업무 웹앱과 별도인 화면 검토용 목업입니다. 실제 PO·원본·계정·문자에 연결하지 않습니다. 예시 날짜는 **2026-10-19**로 고정하고, 작업한 상태는 브라우저의 별도 localStorage 키에 저장합니다. 사이드바의 **예시 데이터 초기화**로 복원합니다.

## 열기

작업 폴더에서 `ops/start-ui-preview.ps1` 실행 후 <http://127.0.0.1:4174/>에 접속합니다. 실제 업무 앱은 기존 8000번 포트입니다. 목업 서버는 설치된 가상환경의 Python 정적 서버를 사용하며 별도 패키지 설치는 필요하지 않습니다.

```powershell
.\ops\start-ui-preview.ps1
```

## 화면과 확인할 상태

| 화면 | 경로 | 주요 검토 항목 |
|---|---|---|
| 업무 달력 | `#/calendar` | 월간·주간·고객/국내외 필터, 날짜 선택, 묶음 업무, 지연·부분완료, 납기 표시, 문자 실패 배너 |
| 업무 상세 | 달력 또는 PO 업무 클릭 | 대상 품목·수량, 기준/자동/최종 업무일, 세부 체크, 수동 이동·자동 복원, 완료 후 재확인·재작업 |
| PO 목록 | `#/orders` | 고객·번호·품목 검색, 국내외 구분, 주문·출고·잔량, 다음 업무 |
| PO 상세 | `#/orders/bj` | 주문 100/출고 70/잔량 30, 회차 수량 한 번 입력, 날짜 변경, 출고 완료·정정, 원본·이력 |
| 해외 상세 | `#/orders/vn` | ETD 미정, 주말 ETD, 후속업무 보류·배치, ETA 안내 |
| PO 업로드·확인 | `#/upload` | 예시 원본과 추출값 비교, 국내외·수령일·통화·납기 확인, 예시 등록 |
| 문자 설정 | `#/settings` | 본인 수신번호, 평일 09시, 오늘+지연, 최종 업무일 기준, 문자 미리보기 |
| 발송 이력 | `#/history` | 전달 완료·최종 실패·결과 확인 중, 상세 사유, 재시도 횟수 |
| 계정·권한 | `#/users` | 관리자/업무담당자와 공동 PO 접근 범위의 시각적 예시 |
| 목업 안내 | `#/guide` | 주요 화면 연결, 실제 업무와 구분 |

## 반복 수정할 파일

| 파일 | 역할 |
|---|---|
| `dist/app.js` | 화면 구성, 탐색, 화면별 클릭 흐름 |
| `dist/styles.css` | 색상·간격·컴포넌트·반응형 레이아웃 |
| `dist/demo-data.js` | 예시 고객·PO·회차·업무·문자 상태 |
| `dist/rules.js` | 목업용 날짜·잔량 계산, 업무 재계산 |
| `tests/rules.test.mjs` | 최종 설계의 날짜·수량 예시 검증 |
| `tests/browser.cjs` | PC·태블릿·모바일 화면과 주요 흐름 검증 |

브라우저 저장 형식이 바뀌면 `app.js`의 KEY/버전과 `demo-data.js`의 버전을 함께 올립니다. 화면 변경 요청은 **화면명 + 변경할 항목 + 기대 동작**으로 정리하면 해당 화면 소스에서 이어서 수정할 수 있습니다.

## 목업에서 실제로 실행하지 않는 것

- 실제 파일 OCR·업로드·원본 다운로드, 실사용 DB 저장, 문자 발송·공급자 조회, 계정 생성.
- ERP·메일·Excel 처리와 인보이스 정보 관리는 포함하지 않습니다.
- 예시 PO는 단일 품목 중심으로 핵심 출고 흐름을 체험합니다. 실제 서비스의 다품목 배정·전체 취소·수정본 연결·동시 수정 충돌 등의 모든 API와 입력 화면을 재구현한 것은 아닙니다.
- 금액·수량 계산은 화면 체험용 JS 숫자입니다. 실사용 서버의 Decimal 정밀도 검증을 대체하지 않습니다.

## 검증 명령

```powershell
node --test ui-prototype/tests/rules.test.mjs
node ui-prototype/tests/browser.cjs
```

브라우저 검증은 작업 폴더에 설치된 `server/e2e/node_modules/playwright`를 사용합니다. 업무 서버나 고객 원본을 호출하지 않고 4174번 목업만 검증합니다.
